# Ecosystem Synergies & Complementary Capabilities

Dynamic Web Architect (DWA) follows the **Adaptive Coexistence Principle**: it owns the **filesystem architecture, DAG dependency boundaries, naming governance, and dynamic file lifecycle plane**, while cleanly complementing adjacent capabilities discovered in the local and global ecosystem without duplicating their responsibilities.

| Ecosystem Capability | What It Owns | How DWA Complements & Interoperates |
| :--- | :--- | :--- |
| **Knowledge Diagram Engine (`knowledge-diagram-engine-workspace-intelligence`)** | Evidence-traceable canonical knowledge graphs, workspace/repo mereology, advisory directory descriptors, JSONC vs JSON Schema distinctions, permission evidence states, and interactive HTML atlases. | DWA adopts JSONC parsing for `tsconfig.json`/`jsconfig.json`, distinguishes Workspace Root vs Repo Root vs Package Root in monorepos, treats `architecture-manifest.json` as an advisory/validation contract (never granting OS/VCS permissions), recommends optional Git worktrees for large migrations, and exports Mermaid DAG diagrams ready for KDE ingestion. |
| **IntentOrbit (`intent-orbit` v3.0)** | Strategic Ends vs. Means separation, 3+1 orbital lenses, BDI bias diagnostics (`OVER_ENGINEERING`, `PREMATURE_OPTIMIZATION`), Transition Cost Guardrail, and Turn 1 Zero-Gate. | DWA embeds the **Transition Cost Guardrail** directly inside `dwa migrate` (`Strategic Value > Implementation Cost + Migration Risk + Operational Fatigue`), applies **Turn 1 Zero-Gate** (inferring defaults labeled `[INFERRED]` instead of stalling), and blocks premature over-engineering on small sites. |
| **Omni Engine V5 (`omni-web-app-classifier`, `framework-registry.json`, `ArchitectureSuiteEngine`, `AdaptiveWebEngine`)** | Multi-dimensional web app classification, 3NF relational schema validation, CQRS read/write segregation, formal ADR ledgers, and Bento HTML/CSS static site generation. | DWA incorporates multi-axis complexity scoring and vertical security profiles (`healthcare`, `fintech`, `ecommerce`, `saas` -> auto-provisioning `core/security/` and `core/audit/`), emits SHA-256 manifest checksums, and hands off relational 3NF / CQRS validation to `ArchitectureSuiteEngine` and visual Bento HTML rendering to `AdaptiveWebEngine`/`omni-web-generator`. |
| **Gemini API (`gemini-api-dev`)** | Interactions API (`v1`/`v1beta`), Decisions API (`gemini-decision-1`), Managed Agents, and modern SDKs (`@google/genai >= 3.2.0`, `google-genai >= 3.2.0`). | DWA automatically detects Gemini/AI SDK usage during `classify`/`init`, provisions a dedicated server-only `src/core/ai/` (or `src/infrastructure/ai/`) boundary, blocks `"use client"` leakage of `@google/genai` via `CLIENT_SERVER_LEAK`, and flags legacy deprecated `@google/generative-ai` imports via `DEPRECATED_AI_SDK`. |
